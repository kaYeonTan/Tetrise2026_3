# 스테이지 3 도안 메모

스테이지 3은 줄을 지워서 HP를 깎는 방식이 아니다.

보드 아래 6줄에 보이는 도안을 맞추면 된다.

- `T`: 채워야 하는 칸
- `E`: 비워야 하는 칸
- `-`: 상관없는 칸

현재 떨어지는 블록은 바로 판정하지 않는다. 블록이 보드에 고정된 뒤에만 판정한다.

2인 온라인은 두 보드를 합쳐서 본다.

- 목표 칸은 둘 중 한 명이 채우면 됨
- 비워야 하는 칸은 둘 다 비어 있어야 함

도안은 `Blueprint.java`에 있다. 새 도안을 넣을 때는 6줄이고 각 줄이 10칸인지 먼저 확인하면 된다.
