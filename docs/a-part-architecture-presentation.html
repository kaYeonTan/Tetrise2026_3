1. 설명용 한 줄 스토리

원래는 JFrame + Board 한 파일에 로직·그리기·키가 다 있던 튜토리얼 구조였고, 지금은 GameEngine/GameSession(규칙), piece(SRS·7-Bag·Hold·펜토), event(버스), ScreenRouter(화면)로 나눠서 B/C가 붙을 자리를 열어 둔 상태입니다.

발표 멘트 예: “Board는 아직 그리기·키가 남아 있지만, 게임 규칙은 Engine/Session으로 빼서 B가 입력·보드를 바꿔도 C가 이벤트만 구독하면 보스 연동이 가능하게 했습니다.”

5. 런타임 흐름 (설명용)

5.1 한 프레임 (PLAYING)

Timer(400ms) → Board.actionPerformed → GameEngine.tick() → oneLineDown() 실패 시 onPieceLanded() → lockPieceToBoard → PIECE_LOCKED → prepareLineClearAnimation (줄 있으면 300ms anim, 입력 막음) → anim 끝 → commitLineClear → LINES_CLEARED(value=줄 수) → spawn

5.2 화면 (Router)

TITLE → MODE_SELECT → GAME(GameParams SINGLE) GAME 중 P → PAUSE overlay (glassPane) Resume → back + unpause Save → SAVE_SLOTS (게스트면 AuthGuard → LOGIN) ※ F-06 본문 미구현 Title → LeaveGuard 확인 → TITLE
발표 멘트 예: “줄 삭제는 명세처럼 연출 후에만 삭제·점수·LINES_CLEARED가 나가서, C팀 StageManager는 버스만 구독하면 됩니다.”
